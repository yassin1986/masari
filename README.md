# مساري

دليل مستقل بالدارجة للتلاميذ فالمغرب على خدمات مسار ومتمدرس. الموقع static بلا إعلانات، تسجيل دخول، نماذج بيانات أو تحليلات مضافة. ما كيجمعش معلومات الحساب المدرسي.

## Sources
- Ministry of National Education: https://www.men.gov.ma/fr
- Official Moutamadris student portal: https://moutamadris.men.gov.ma/
- Official Massar Waliye parent/guardian portal: https://massarservice.men.gov.ma/waliye
- Ministry announcement about Massar spaces: https://www.men.gov.ma/Ar/Pages/Publication.aspx?IDPublication=4785

The Ministry’s current services page describes Moutamadris as a student space and Massar Waliye as a space for parents/guardians, with school-path details including timetable, grades/results, homework, scheduled exams and absences; Waliye also includes school activities. A Ministry announcement separately names the two official spaces and their intended audiences. Guide text is high-level; it avoids unverified account recovery instructions. This independent site is not affiliated with the Ministry.

## Deploy
This repository is intended for GitHub Pages from the `main` branch root. No custom domain, paid hosting, third-party scripts, ads or user credentials are required.
